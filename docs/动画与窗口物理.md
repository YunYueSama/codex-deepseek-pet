# 动画与窗口互动

大肥鱼采用八组主动作和扩展表情：待机/走路各 16 帧，其余主动作各 8 帧，完整原画共 112 帧。`motion.js` 按时间采样、控制循环与收尾；部分情绪仍为关键姿势序列。

渲染目标 60 FPS，画布按显示尺寸与屏幕 DPI 绘制。每帧清空后只绘制一个角色，不叠加前后姿势；动作切换用 180ms 曲线衔接重心、倾角和形变，不混合两张原画。此过渡不生成新的肢体中间帧，原画差异仍可能看出切换。

命中检测使用预载的 1 位透明度阈值掩码，避免每帧回读主 Canvas。六张图集合计 4 MiB，相比原先逐像素字节掩码的 32 MiB 减少 87.5%；这不是整个应用内存的降幅。加载时逐张、分条带读取透明度，并释放临时 Canvas，绘制仍使用原尺寸图片。隐藏、锁屏与减少动画模式采用较低更新频率。

拖拽时随速度倾斜、拉伸，松手后保留近期速度并受重力下落。跨帧落点检测避免高速穿过窗口顶边；落地压缩与回弹采用衰减曲线。窗口消失、最小化或完全遮挡后失去支撑，下落到其他窗口或屏幕工作区底部。

Windows 探针每 500ms 读取最多 64 个可见窗口的几何与 Z 序，不读取标题或页面文字。遮挡部分不能承托；窗口坐标转换为 Electron DIP。已承托时跟随窗口移动，自动散步限制在可用顶边。顶边太靠近屏幕顶部时不承托，以保留角色可见部分。目前不包含侧壁攀爬或完整刚体碰撞，快速移动窗口可能出现采样延迟。

大小支持 0–100%：100% 对应 300px 宽的角色画布；0% 隐藏。极小时宿主窗口仍保留 Windows 要求的 32px，但角色按真实比例缩放，脚底计算使用角色尺寸。旧的超过 100% 设置读取时限制为 100%。

参考过用户指定的「糯糯桌宠-免安装版」：其发行资源含 18 组、每组 16 张序列帧，公开程序符号体现帧时序与平台落点机制。仅学习序列帧、弹性和平台交互思路，没有取得完整源码，也未复制角色图片、音频或实现代码。

2.3 默认采用用户指定标准的正面立绘，仅一条鲸尾。约 4–9 秒眨眼一次，眼周短促切换完整闭眼帧，避免逐行遮眼的白带；脸和身体不整幅切换。

自在陪伴时，每次动作结束后休息 18–32 秒，再做约 3.2 秒的重心调整、轻轻放松或深呼吸，避开最近两种，不附带台词。启动散步等待约 45 秒，完成后间隔 60–110 秒；互动或拖拽后至少等待 90 秒再散步，用户操作和其他动作优先。低饱腹时才表现饥饿，媒体场景才可能哼歌，这类表现启动至少三分钟后出现，之后至少间隔五分钟；不再无缘由地随机探头、得意或从睡姿伸展。专注、安静、聊天、离开与全屏状态不触发这些自主动作。

走路仍稳定上半身、更新裙摆以下步态，起伏与步频同步。思考保持姿势，短舞蹈结束后回到待机。用户互动会延后自主动作，相同动作进行中不会因连续事件重启。气泡使用 15px 高对比文字，聊天从双击、回车或托盘进入。旧动作原画尚未全部按新角色标准重画。
