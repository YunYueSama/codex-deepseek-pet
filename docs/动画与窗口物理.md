# 动画与窗口互动

3.0 使用重新绘制的 24 张分层图片：15 张正面部件与道具，加上 9 张斜侧视头部、躯干、后发和四肢。鲸尾只有一条。旧版整图序列不参与运行。独立程序按时间连续计算 31 种动作，以 60 FPS 为目标；不是把几张整图交叉淡化。

`motion.js` 管理骨架姿势、动作阶段、二段手脚 IK 和 220ms 关节过渡。`rig.js` 使用 WebGL2 三角网格，肘膝附近平滑分配关节影响，头发、裙摆和鲸尾使用连续变形。所有相邻网格共用边界，避免 Canvas 条带接缝。预乘透明度配合 mipmap 缩小滤波，减少彩边和细线闪烁；画布随角色大小和屏幕 DPI 调整。

走路分为支撑和抬脚阶段；吃 token 分为伸手、送入口、咀嚼和收手；睡觉通过屈膝、降低身体、歪头和闭眼进入。动作之间只插值骨架，不叠加两个人物轮廓。面部在固定头部内局部换图，眨眼约 4–9 秒一次。无 WebGL2 时降级为 Canvas 网格，软件渲染不保证 60 FPS。

自在陪伴时，每次动作结束后休息 18–32 秒，再做约 3.2 秒的重心调整、放松或深呼吸，不附带台词并避开最近两种。启动约 45 秒后可散步，完成后间隔 60–110 秒；互动或拖拽后至少等待 90 秒。低饱腹才表现饥饿，媒体场景才可能哼歌；这类表现启动至少三分钟后出现，之后至少间隔五分钟。专注、安静、聊天、离开和全屏状态不触发自主动作。

拖拽保留速度惯性，松手受重力下落；跨帧落点检测避免穿过窗口顶边，落地压缩与回弹逐渐衰减。Windows 隐藏探针每 500ms 读取窗口几何与 Z 序，不读取标题或页面文字。被遮挡顶边不承托；已承托时跟随窗口移动，窗口消失后下落。快速移动窗口可能受采样延迟影响。

大小支持 0–100%，100% 对应 300px 角色画布，0% 隐藏。极小时宿主窗口仍满足 Windows 32px 限制，角色与脚底计算使用实际比例。命中通过已绘制三角形的逆映射与源 alpha 位图判断，不每帧回读 GPU 画布。

Codex 包从同一套骨架烘焙，保持 desktop 1536×2288 / web 1536×1872 宿主契约；它不包含独立程序的实时骨骼和窗口物理能力。

默认待机正面，行走朝行进方向斜侧身；取食、探头、伸展和入睡会转动身体。肩胯反向摆动，头部延后跟随，远近手的遮挡顺序随视角变化。关节和重心连续插值，但正面与斜侧视素材、表情仍按关键姿势切换，没有完整侧背面、任意角度转身或口型语音同步，不等同于完整的 Live2D/Spine 编辑器工程。
