# 动画与窗口互动

动画采用完整角色 2D 原画：走路 32 帧，待机 16 帧，进食、挥手、跳跃、跳舞、偷吃和入睡各 16 帧，另有情绪关键姿势与 8 帧方向原画。完整流程与角色约束见 [2D 角色与动作规范](2D角色与动作规范.md)。

渲染目标 60 FPS，Canvas 按显示尺寸和屏幕 DPI 配置。每帧清空后仅画一个完整角色，不叠加前后姿势，不裁切拼接眼睛、腿或躯干；动作切换的 180ms 曲线只衔接重心与整体变换，不能制造未绘制的肢体中间帧。

命中使用每像素 1 位透明度阈值掩码，加载时逐张分条带读取，不逐帧回读主 Canvas。素材扩帧会增加图像内存；掩码占用不代表应用总内存。实际本机采样见验收记录。隐藏、锁屏和减少动画模式降频。

散步前先用 600ms 转身，再缓起步；靠近目标减速，停下后用完整方向帧回正。可用边缘太窄或目标太近时跳过本次散步，防止原地抖动。自主散步完成后间隔 60–110 秒，用户互动会延后散步。

待机身体调整在动作结束后间隔约 18–32 秒触发，避开最近两种；眨眼间隔约 4–9 秒。有限动作结束即释放行为占用。专注、聊天、安静、离开和全屏状态抑制自主动作；饥饿和哼歌需要相应状态。入睡通知不重复重置动画，返回时先起身。

拖拽随速度倾斜与轻微拉伸，释放后保留近期速度并受重力影响。跨帧落点检测避免高速穿过窗口顶边；落地按衰减曲线压缩和回弹。窗口消失、最小化或完全遮挡后失去支撑。

Windows 探针每 500ms 读取最多 64 个可见窗口的几何与 Z 序，不读取标题或页面文字。遮挡区域不能承托，坐标转为 Electron DIP；承托时跟随窗口移动。顶边过高时不承托以保留角色可见部分。没有侧壁攀爬或完整刚体碰撞，快速移动窗口可能有采样延迟。

大小支持 0–100%，100% 为 300px 画布，0% 隐藏；极小时宿主窗口最小 32px，角色及脚底仍按实际比例计算。
