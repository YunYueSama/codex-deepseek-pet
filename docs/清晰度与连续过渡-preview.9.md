# preview.9：清晰度与连续动作

待机与面板立绘改用独立高清原画：每个人物实际高 982px，一次缩小到 820px，放入 1024px 单元。此前从多帧小格放大的人物约高 180px，无法保留眼睛与衣服线条。原图、提示词与构建说明见 [idle-hq-v1](../design/sources/idle-hq-v1/README.md)。

![同为 300px 显示：左为旧版，右为新版](clarity-comparison-preview9.png)

走路、招呼、吃东西、偷偷哼歌加入双向运动场过渡。每次只采样一张完整角色原画，在两张原画之间连续移动像素；不拼接肢体、不叠加两个轮廓。其他动作继续使用现有完整角色帧。走路相位跟随窗口实际移动距离，起步和刹车时脚步同步减慢。

这仍是二维原画加图像变形，不是完整骨骼动画，也不是每秒 60 张独立原画。较大的姿势差异仍可能出现局部形变，需要继续修整源图。本轮试画的新步态因跨图造型不一致，未接入运行版。

## 运行与维护

- WebGL2 提供连续过渡；不支持或上下文丢失时退回原始整帧播放。
- 预热 80 张 GPU 纹理，增加约 66MiB 纹理预算，换取播放期间避免首次上传。不是内存优化版本。
- 修改相关原画后运行 `npm run assets:flow`。开发端需要 Python、NumPy、OpenCV；可通过 `PET_FLOW_PYTHON` 指定解释器。运行 EXE 不依赖 Python。
- `tests/flow.test.cjs` 校验原画散列与过渡配对，防止旧运动场对应新原画。

## 本机验证

- 63 项单元测试及代码检查通过。
- 原生窗口左右各移动 90px，方向、落点、起停节奏与步态位移时钟通过。
- 固定 60Hz 采样的 115 个步行间隔，原始整帧有 83 次画面保持；插值后为 0 次。帧间像素差异 p95 从 9.792 降至 7.083。这是连续性指标，不代表人体动作完全自然。
- 左右朝向、插值前后半段共 38,781 个非边缘点击采样，命中结果无差异。
- 正常速度录制检查覆盖走路、招呼、吃东西与哼歌。
- 完整 Electron 集成通过，包括聊天、喂食、专注、游戏、拖拽、大小调整、窗口边缘承托与移除。
- 实际 portable EXE 启动烟测通过：262 张角色帧加载完成，WebGL 连续过渡启用，窗口截图为 300×360；包内九项关键代码与资源逐字节匹配工作区。
- 稳态步行短测 60.00 FPS，帧间隔 p95 17.2ms、最大 18.4ms；全动作短测 60.09 FPS，p95 18.3ms、最大 22.4ms。不是所有设备或长时间运行保证。

开发验证记录位于本机 `artifacts/flow-qa/`、`artifacts/walk-qa-v9/` 与 `artifacts/revision9-flow-visual/`，不进入安装包。
