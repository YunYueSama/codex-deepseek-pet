# 大肥鱼：完整角色 2D 动画规范

## 唯一造型标准

以 [角色标准图](../design/character-standard.png) 为准：低饱和蓝紫长发、浅蓝发梢，圆蓝虹膜、深色瞳孔和明显上睫毛；深蓝女仆裙、白色鲸鱼围裙、金色裙边、白蓝侧鳍与一条鲸尾。她聪明、贪吃、偶尔嘴硬，吃饭和 token 都是补充精力。饭碗不作为固定配件。

默认站姿正面、双臂自然垂下。走路时头、胸廓、骨盆、手臂与腿一起改变姿势，不能保留正面躯干只替换腿。转向使用完整方向原画，不能用横向压扁立绘模拟旋转。

## 动作流程

| 场景 | 顺序与约束 |
| --- | --- |
| 散步 | 正面 → 转向 → 缓起步 → 完整步态循环 → 减速 → 收步转回正面。转向前 600ms 不移动窗口。 |
| 待机 | 中立站姿与间隔眨眼为主；每隔约 18–32 秒选择一次短身体调整，避开最近两种动作。 |
| 吃东西 | 取食 → 举起 → 咬食 → 咀嚼 → 放下；只在喂食或对应情境触发。 |
| 跳跃与落地 | 屈膝准备 → 离地 → 腾空 → 接地 → 压缩回弹 → 站稳。 |
| 离开与返回 | 空闲三分钟后入睡；重复空闲通知不重播入睡，返回先起身。 |
| 专注、聊天、拖拽 | 抢占自主散步和随机动作；低优先级动作不能打断用户交互。 |

有限动作播放完毕即释放行为占用，避免画面回到待机后仍被旧动作锁住。循环仅用于散步；短表演不机械循环，情绪动作需要用户操作或环境依据。

## 参考方式

研究了本机「糯糯桌宠-免安装版」发布目录中的 18 组动画资源，观察完整角色步态、落地压缩和入睡过程。发布目录不等于源码；本项目借鉴动作分组与准备、执行、恢复的组织方式，自行实现行为与物理逻辑，未引入其角色素材或程序代码。

## 绘制与验收

新原图位于 `design/sources/hq-v4/`，通过内置 imagegen 依据标准图重新绘制。品红背景只用于离线抠图；运行资源必须有真实 alpha、干净边缘和完整安全边距。完整提示词随生成记录保存。

运行时使用单层实像，不叠加前后帧，不裁出眼睛或腿拼接。画布按显示尺寸与系统 DPI 配置，目标 60 FPS；原画帧率与屏幕渲染帧率分别说明。

验收覆盖源图、全部动作的实际 Canvas 输出、眨眼与走路连续采样、帧率和帧间隔，以及动作时长、转向、抢占、防重复、睡醒和窗口承托。截图与短时测试只能说明本机已测场景，不能保证所有硬件和窗口环境都无问题。
