# 开发指南

## 本地开发

Windows x64，Node.js 20+。运行 `npm ci` 恢复依赖，`npm start` 启动桌宠，`npm run dev` 开启调试。发布的运行素材已经包含在仓库中，首次启动不需要生成图片。

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run test:electron
npm.cmd run test:integration
```

原生窗口与全部动作绘制验证：

```powershell
$env:PET_TEST_EDGES='1'
$env:PET_TEST_VISUAL='1'
npm.cmd run test:integration
```

测试使用隔离的用户目录和本机模拟聊天服务，不使用真实密钥。截图写入 `docs/`，性能诊断写入 `artifacts/`；短时数据不能代替长期、多屏和混合 DPI 验收。

## 构建与素材

2.3 的角色标准、正面眨眼原图与独立图标原图位于 `design/sources/brand/`，说明及最终提示词要点见该目录 README。`npm run assets:brand` 只重建这些素材及 Codex 外观包；完整素材构建也会调用它，避免独立图标被全身立绘覆盖。

`npm run dist` 生成安装版和免安装版到 `artifacts/`。EXE 不进入 Git 历史；发布时放到 GitHub Releases。仓库已有基于版本标签的发布工作流，推送普通源码提交不会自动发布安装包。

```powershell
npm.cmd run assets:build
npm.cmd run icon
node scripts/build-motion-preview.cjs
```

高清原图保存在 `design/sources/hq/`，中间透明图及编译报告统一写入可删除的 `artifacts/hq/`。成品图集、立绘、图标和 Codex 外观包随仓库提供。字体使用本地 Noto Serif SC 分段 WOFF2 与 OFL 许可；仅需更新字体时运行 `npm run assets:fonts`。

若构建工具下载缓慢，可在当前终端设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 与 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`。安装包未签名；构建日志出现 signing 步骤不代表具有有效签名证书。

## 目录

| 路径 | 用途 |
| --- | --- |
| `src/main/` | 状态机、窗口物理、应用感知、聊天与设置 |
| `src/renderer/` | 桌宠绘制与陪伴面板 |
| `src/preload.cjs` | 受限 IPC 桥 |
| `assets/whale/` | 成品角色图集 |
| `assets/fonts/` | 本地字体与许可 |
| `design/` | 角色设计、高清原图与提示词 |

`node_modules/` 与 `artifacts/` 均可重新生成。个人 `.env`、密钥、日志和本机 EXE 不提交到仓库。

## 接口与隐私边界

聊天兼容 OpenAI Chat Completions。手动聊天请求 SSE 流式回复，自动画面观察仍使用整段回复；服务若忽略流式参数而返回 JSON，也可正常显示，不自动重试或重复计费。支持取消与 45 秒整次请求超时，取消或断流后保留页面已显示的文字，但未完成的一轮不写入模型对话历史。只显示正文，不显示模型推理字段。远端服务要求 HTTPS，本机回环地址允许 HTTP。密钥单独存储并由系统加密，更换服务域名时清除已有密钥。聊天历史仅在内存中保留。

前台应用判断不读取标题。画面分享默认关闭，自动观察最多两分钟一次；专注、安静、锁屏与离开时暂停，全屏暂停受设置控制。图片会发往用户配置的兼容服务，文本模型不能处理图片。模型输出不用于执行系统命令。

Codex 桌面 v2 外观表为 1536×2288，网页表为 1536×1872。两种规格不得混用；导出外观不会导出聊天、游戏和窗口物理能力。不同 Codex 宿主需实际导入验收。

## 已验证与仍需验证

2.3 增加默认正面立绘、独立图标和分层待机节奏：46 项单元测试（含修复后重跑的素材检查）通过；实际 Electron 验证了流式聊天、窗口承托、缩放和 31 种动作，短时全动作约 60.00 FPS、p95 17.5ms。新默认图集替换运行时旧待机图集后，命中掩码合计约 3.56 MiB。图标检查覆盖 16/32/48/256px ICO 与 512px PNG。

2.2 已通过语法检查、43 项单元测试，以及模拟流式聊天与中途取消、喂食、专注、小游戏、0–100% 大小调节和原生窗口承托/跟随/移除的实际界面集成验证。免安装 EXE 已通过启动与 300×360 截图检查；安装包已构建，未执行交互安装。2026-09-14 本机短时测量覆盖 28 种动作，全动作平均 60.00 FPS、p95 16.9ms；命中掩码为 4 MiB，不代表应用总内存。原生窗口测试使用无遮挡的置顶测试窗口，避免把其他应用遮挡造成的不可承托误判为故障。

真实模型的回复质量和视觉兼容、不同 Codex 宿主、低配置电脑、长时间内存使用、多屏混合 DPI 和特殊窗口仍需进一步验证。当前包含序列帧与关键姿势，尚非完整骨骼动画，也没有流式语音或自动操作电脑。
