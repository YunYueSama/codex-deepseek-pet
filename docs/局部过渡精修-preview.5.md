# 局部过渡精修 · preview.5

这轮针对 preview.4 中的尺寸跳变和极短过渡帧，没有增加原画数量。

- 跳跃的 5 张完整原画做等比例校准：缩小过大的蓄力、落地蹲姿，放大偏小的起跳、回正姿势。脚底位置保持一致，不拆分头部或肢体。
- 走路的两张换步补帧分别水平对齐 12、20 像素，减轻头颈中心前后跳动；保留原尺寸。
- 跳跃、落地的每张画面至少停留 40 毫秒。跳跃总长由 1080 调为 1195 毫秒，腾空区间为 240–720 毫秒；落地恢复总长为 605 毫秒。身体位移和动作阶段共用调整后的时间线。
- 校准仅发生在素材编译阶段，保持原有图集尺寸和单层绘制，不增加运行时纹理或交叉淡化。原始素材不覆盖，可用 `node scripts/build-inbetweens.cjs` 重现。

## 检查记录

真实 Electron 画布按 1 倍速录制了走路、跳跃、落地、睡眠。检查了相邻姿势接触表、前后对照图和正常时钟的采样画面；这不等于已经逐帧人工观看完整视频。

| 动作 | 录制期间平均画布 FPS | P95 间隔 | 最大间隔 |
| --- | ---: | ---: | ---: |
| 走路 | 55.6 | 18.1 ms | 115.4 ms |
| 跳跃 | 59.1 | 17.0 ms | 82.7 ms |
| 落地 | 60.0 | 16.9 ms | 17.7 ms |
| 睡眠 | 58.9 | 17.6 ms | 96.3 ms |

录制有编码和截图开销，这些数值不能代替无录制运行的性能结论。测试覆盖原生窗口顶边落脚、支撑窗口移动与移除，以及聊天、拖动、缩放等交互。睡眠本轮只复查，未修改原画。

60 项单元测试及语法检查通过。首轮录制已完整写出视频和报告，但测试程序退出超时；已改用正常退出流程清理窗口探测器，随后单独录制落地动作正常退出。该次复测平均 57.8 FPS，最大间隔 171 ms，也说明录制下仍存在偶发长帧。

本地证据位于 `artifacts/polish/comparison.png` 与 `artifacts/polish-final/`。动作仍由离散原画组成，尾巴、发梢和不同批次的造型仍有局部差异；本轮没有宣称所有动作达到无跳变或稳定 60 FPS。

最终 portable EXE 启动截图检查通过（300×360），包内动作代码和三张中间帧图集与源文件逐字节一致。`Whale-Companion-3.1.0-preview.5-portable.exe` 已放到项目根目录；本轮未提交或发布 GitHub。
