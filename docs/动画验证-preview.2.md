# preview.2 动画验证

2026-09-16，本机 Windows，Electron 43.1.0。

- 56 项单元测试通过，包括素材有效帧、透明边距、色键残留、3–5 秒待机节奏、冷却、打断、物理与聊天。
- `node scripts/story-qa.cjs` 从实际 Electron Canvas 导出 37 组动作/派生状态预览；逐帧预览在本机 `artifacts/story-qa/`。
- 四组新剧情运行期间短时采样：807 帧，59.42 FPS，P95 帧间隔 17.8 ms，最大 70.3 ms。该值不是长时全场景性能保证；逐帧导出的其它动作不计作实时 FPS 采样。
- 命中掩码占 13,893,632 字节；此数不是应用总内存。
- 原生 Electron 集成测试通过：外部窗口落地、窗口移动时跟随、支撑窗口移除后下落，以及本地模拟流式聊天、取消、设置、喂食、专注、拖拽尺寸和小游戏。
- 便携 EXE 启动烟测通过，生成 300×360 实际窗口截图；检查打包内版本号、最新动作序列及新图集一致。文件放在项目根目录，尚未发布此版本到 GitHub。
- 测试了 0%、1%、42%、100% 大小；0% 隐藏宠物，极小尺寸受到 Windows 最小宿主窗口约束。

## 视觉筛选

走路采用独立重画的 32 张完整原画；吃东西、挥手、跳跃、跳舞和入睡各 32 张。偷吃的旧金色道具与新蓝色 token 不一致，剔除后使用 22 张。重新排列睁闭眼、入睡尾巴收拢和跳跃身体阶段，未用叠帧淡化掩盖变化。

新绘转身出现疑似双尾的形态，未接入，保留原有 8 张转身。部分情绪仍使用关键姿势，不应宣传为全部动作均已连续重画；全身逐帧的局部线条、尾巴轮廓和循环接缝仍有进一步精修空间。60 FPS 渲染不等于每秒 60 张独立原画。

源图与内置 imagegen 提示记录：`design/sources/stories-v1/`、`design/sources/dense-v1/generation-log.json`。本次未下载模型、未加入真实语音，也未接入测试运行状态。
