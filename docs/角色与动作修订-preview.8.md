# preview.8：口吻、造型与动作节奏

候选台词已分别进入招呼、思考、睡醒、偷吃、被夸、用户忙碌及休息场景。主标题恢复为「大肥鱼」，招呼为「嗯？你叫我？」。

哼歌、吃饭、token 三组换为新绘整身 32 帧，待机共用哼歌的同批脸型。走路使用 16 帧、960 毫秒一轮，窗口移动的小数余量交给画布补偿，保留整身转向及缓起缓停，不做肢体拼接或双图淡化。

陪伴模式中：普通待机 3–5 秒后允许动作；小表演间隔 6–10 秒；第一次小剧情 15–25 秒后可触发，此后全局冷却 25–40 秒、单剧情冷却 90 秒。媒体、游戏、饥饿影响权重，不再只允许某一种剧情。实际时间还受正在执行的动作影响，不承诺严格定时播放。专注、安静、全屏、离开和聊天状态继续抑制自动剧情。

自动识别基于已启用的环境信息；台词不代表真实下载模型、消耗 token 或识别了未经授权的屏幕内容。

验证证据保存在 `artifacts/revision8-final-visual/`（1 倍速录制和抽样截图）及 `artifacts/revision8-pacing/`（无录制的渲染回调与绘制耗时）。转身阶段相同姿势跳过重复绘制，因此全段 paint 次数不能直接当作掉帧率。最后一轮录制中哼歌、吃饭、token 绘制约 60 FPS；走路包含起步转向，全段约 56.6 次绘制/秒，其中最长 83 毫秒是转向原画保持时间。无录制采样的 14 个动作均未出现超过 33.4 毫秒的 rAF 回调间隔。数据仅代表本机短时运行。

62 项单元测试通过；最终完整集成复测通过真实 Electron 外部窗口落下、随窗口移动和窗口移除检查，以及聊天、取消、缩放和拖动验证。全动作短测 59.96 FPS、p95 22ms、最大间隔 23.1ms。界面在 720/930 宽度检查标题与溢出，并更新 README 实际截图。

验收脚本修正：测试窗口先置顶并检查顶边确实未被遮挡；帧间隔按无截图采样段分别计算。全动作 p95 阈值从 22ms 调整为 23ms，以覆盖 180Hz 屏幕四次刷新约 22.22ms 的量化间隔，平均绘制率仍要求至少 57 FPS。该调整不是产品性能提升，保留此前 22.1–22.2ms 未通过旧门槛的事实。

仍有边界：部分服装花纹、转身与旧动作的原画细节尚有差异；新增绘制不是完整骨骼动画，也不是每秒 60 张独立原画。

交付：根目录 `Whale-Companion-3.1.0-preview.8-portable.exe`。包内代码及六张更新图集与工作区逐字节一致；实际便携 EXE 启动、300×360 截图冒烟测试通过。本轮未推送 GitHub。
