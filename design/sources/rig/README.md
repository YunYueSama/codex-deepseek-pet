# 大肥鱼分层原画

依据 `../brand/character-standard.png` 绘制，沿用低饱和蓝紫发色、深蓝白裙、金色细节、微嘟嘴与单鲸尾。素材由内置 image_gen 生成；品红底经用户授权在本地处理，源文件保留用于重新编译。

三张原画的最终构图约束：

- `parts-magenta.png`：3×3 独立部件。依次为躯干、后发、尾巴；左臂、右臂、左腿；右腿、token、口粮袋。四肢完整，部件之间留空。
- `heads-magenta.png`：3×2 等比例头部，中立、闭眼、开心、得意、鼓腮、星星眼；保留完整发饰轮廓，各头部互不相连。
- `side-magenta.png`：向画面右侧约 45 度的真实斜侧视，3×3 排列。前三格为中立、闭眼、微笑头部；第二行为躯干、后发、远手；第三行为近手、远腿、近腿。不画第二条尾巴，复用正面单尾。

共同提示词约束：严格参考指定角色的颜色、眼型、服装和发饰；纯 RGB(255,0,255) 背景；无棋盘格、文字、投影；各部件留足间隙。首轮头部间距不足的稿件未使用。

`scripts/build-rig.cjs` 提取 24 个连通部件并去除背景混色。原生部件最大 512px，不通过放大伪造分辨率。运行时使用共享边界三角网格、手脚两段关节与视角部件选择。斜侧视仅有三种头部表情，其他情绪映射到其中最接近的一种；当前没有完整侧面或背面原画。
