# 角色标准统一重绘

`../../character-standard.png` 是唯一角色标准，2026-09-23 用户再次确认的参考图与仓库文件逐像素相同。新版高清待机原画与独立应用头像按该图重绘；旧版图稿保留在原目录，供历史比对，不再作为待机或图标构建输入。

## 新版待机图

- 源文件：`idle-pair-magenta.png`，左图睁眼、右图闭眼；同一正面姿势与尺寸。
- 生成方式：内置 imagegen，分别把标准图作为造型参考、把旧高清待机对作为构图和姿势参考。
- 抠图：纯品红底由 `scripts/key-motion.cjs` 离线转为真实 alpha；边缘去溢色，不对角色主体做颜色替换。
- 构建：`npm run assets:idle` 会编译为运行待机图与面板立绘；完整素材构建也会重新生成它们。

待机图的完整提示词保存在同目录 `prompts.md`。关键约束是严格保持标准图的蓝紫至浅蓝长发、圆蓝眼睛、白色褶边头箍、蓝色鲸鱼发饰、深蓝女仆装、白色蓝鲸围裙和单根尾巴。两帧只切换眼睛开合，不改姿势、比例或服装。纯品红底用于抠图，不包含棋盘格、文字、阴影或动作残影。

## 独立头像

- 源文件：`app-icon-redraw.png`，透明背景、单人头肩构图，保留完整呆毛、头箍、侧鳍与蓝色蝴蝶结，并让围裙蓝鲸图案在小图标中可辨认。
- 生成方式：内置 imagegen，以标准图锁定角色身份，以旧独立图标参考方形头像构图；完整提示词也记录在 `prompts.md`。
- 构建：`npm run assets:brand` 直接消费此透明原图，另行编译 Windows 图标与 Codex 外观包。

动画候选必须逐帧保持原姿势与动作节奏。若生成结果重复姿势或改变步态，不得替换已验证的动作序列。
