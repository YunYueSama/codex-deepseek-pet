# 同一只大肥鱼

依据用户提供的 `codex-clipboard-cdd22cdf-be73-489e-a6eb-0bb84188dde7.png` 重绘：蓝紫头发、浅蓝发梢、半睁蓝眼睛、海军蓝与白色鲸鱼女仆服、单尾。

使用内置 imagegen 生成整身原画，提示词保存在 `prompts.json`。原图保留纯品红背景，构建脚本执行已获用户授权的本地透明化，不拆分骨骼。

`node scripts/build-stories-v2.cjs` 编译哼歌、吃饭、token 各 32 张原画及走路 16 张原画；待机取同批睁眼与闭眼姿势。运行仍采用整体序列帧，不把显示刷新率说成独立原画数量。
