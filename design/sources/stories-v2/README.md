# 同一只大肥鱼

连续剧情姿势最初依据用户提供的社区参考图绘制。外观仍以 `design/character-standard.png` 为唯一标准；构建时会同步新版高清待机原画中的蓝紫配色。

使用内置 imagegen 生成整身原画，提示词保存在 `prompts.json`。原图保留纯品红背景，构建脚本执行已获用户授权的本地透明化，不拆分骨骼。

`node scripts/build-stories-v2.cjs` 编译哼歌、吃饭、token 各 32 张原画及走路 16 张原画；待机取同批睁眼与闭眼姿势。运行仍采用整体序列帧，不把显示刷新率说成独立原画数量。

哼歌、吃饭和 token 的蓝色调色在整组帧上统一计算，并从新版高清待机原画校准色相与饱和度；不会逐帧单独调色，避免播放时闪色。白色、肤色和金色细节不参与校准。每次构建的校准结果记录在 `artifacts/stories/palette-normalization.json`。

用户参考的原作者及来源链接尚待补充，参考图的权利不因本仓库许可而转移。
