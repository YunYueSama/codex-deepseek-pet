# 角色标准与独立图标

`character-standard.png` 是用户于 2026-09-14 指定的外观实现标准。它作为参考资料保留，不因此取得第三方参考作品的额外授权。

后续角色绘制以此图为准：低饱和蓝紫色长发与较浅发梢、深蓝裙装、白色蕾丝、金色细节；眼型、上眼线和高光位置参考正面图，默认小嘴微嘟，不使用甜笑或夸张圆眼。左右发饰按标准保留，鲸尾严格只有一条，从身后伸出，正面仅在画面右侧少量露出。

`front-idle-magenta.png` 是重新绘制的正面睁眼与闭眼原图；`app-icon-magenta.png` 是独立绘制的头像图标，不是全身立绘的缩小裁切。两者均使用内置 image_gen 生成，再用已获授权的本地透明背景处理编译。先前高饱和、双尾的草稿没有接入应用。

最终提示词要点：严格参考用户设定图；保持低饱和蓝紫配色、克制眼神和微嘟小嘴；正面帧只改变眼睑，保持身体、发型及脚底对齐；仅一条鲸尾；独立图标用大头像和深蓝圆角底，适合小尺寸识别；纯 RGB(255,0,255) 底用于抠图，无棋盘格、文字或阴影。

3.0 已重新绘制全部运行部件，位于相邻的 `../rig/`。此目录的正面站姿原图仅作历史记录。运行 `npm run assets:brand` 编译独立 PNG/ICO 图标，并从当前骨架生成面板立绘与 Codex 包；`npm run assets:build` 同时重建全部正面和斜侧视部件。
