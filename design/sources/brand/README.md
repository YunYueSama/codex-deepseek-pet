# 角色标准与独立图标

唯一标准是 `../../character-standard.png`。低饱和蓝紫长发、浅蓝发梢、圆蓝眼睛、深蓝白金裙装、白蓝侧鳍、一条鲸尾。

`app-icon-magenta.png` 由内置 image_gen 独立绘制，再以已获授权的本地透明处理编译为 PNG 与多尺寸 ICO。它是头像图标，不是全身缩略图。

图标提示词要点：严格使用标准图角色；正面头肩、大蓝眼睛、深色瞳孔、小嘟嘴、完整呆毛和蕾丝；深色清晰轮廓与简单赛璐璐明暗；适合 32px 辨识；单尾；品红背景用于抠图，无文字、棋盘、额外角色。

默认正面与闭眼直接取自 `../hq-v4/` 新待机原画；`npm run assets:brand` 消费已构建的待机图集并重建图标及 Codex 包。完整构建为 `npm run assets:build`。
