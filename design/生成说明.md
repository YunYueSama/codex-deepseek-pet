# 素材制作说明

角色标准为用户于 2026-09-14 指定的 `sources/brand/character-standard.png`。造型保持低饱和蓝紫头发、克制眼神、微嘟小嘴、深蓝白裙与单条鲸尾；权利边界见 [素材说明](../ASSET_LICENSE.md)。

3.0 全部运行部件重新使用内置 image_gen 绘制：

- `sources/rig/parts-magenta.png`：躯干、后发、鲸尾、左右手臂、左右腿与口粮道具。
- `sources/rig/heads-magenta.png`：中立、闭眼、开心、得意、鼓腮、星星眼六组表情。
- `sources/rig/side-magenta.png`：朝右斜侧视的三组头部、躯干、后发和四肢，朝左由镜像显示。
- `sources/brand/app-icon-magenta.png`：独立设计的头像图标。
- `character-sheet.png`：由真实骨架绘制的当前造型与六组表情，不是旧版本模型图。

最终提示词约束：严格匹配指定标准的配色、眼型、发饰和服装；只保留一条鲸尾；模块分离且完整保留轮廓；头部各表情保持比例与位置一致，不包含后发和身体；纯 RGB(255,0,255) 背景，无棋盘格、阴影或标签。图标独立构图，头像需在小尺寸下可辨认。

在用户已授权的本地透明处理下，`build-rig.cjs` 去除品红底和外沿混色，按连通区域提取部件，保留原生像素，生成 `assets/whale/rig/`。`build-brand.cjs` 仅编译独立图标。`build-assets.cjs` 启动隔离 Electron 绘制当前骨架，生成面板立绘、Codex 包及动作过程图。`npm run assets:build` 可完整重建。

早期 `sources/hq/` 和品牌站姿草稿保留作历史设计记录，不再参与 3.0 构建；旧运行图集已移除。新动画是骨架驱动的连续网格变形，六组基础表情仍是局部图像切换。
